# Мопед.NET
Система подготовки дата-центров к угрозе отключения площадки.

«Ваш uptime не должен зависеть от чужого карбюратора».

Учебный архитектурный проект для команды из трёх человек. Часть 1: архитектура и контракты, без реализации сервисов. Часть 2: пять сервисов и симулятор инфраструктуры. Дата проектирования: 27 октября 2026.

## Начать здесь
- [Для показа на защите](docs/defense/README.md)
- [Навигация по пяти артефактам](docs/README.md)

Откройте `docs/architecture.html` в браузере: автономный справочник с отрисованными диаграммами. Материалы для показа находятся в `docs/defense/`, для подготовки команды — в отдельном репозитории `moped-net-preparation`. Исходники Mermaid находятся в `docs/diagrams/`. Спецификации OpenAPI и AsyncAPI записаны в JSON, одном из поддерживаемых ими форматов.

Никаких реальных команд отключения, учётных данных, обнаружения или противодействия угрозам в проекте нет. Система получает готовый внешний сигнал и управляет безопасным переносом ИТ-нагрузки.
